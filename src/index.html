    What this tool cannot see

    • The BSP’s reference data about your bank. Enter the facts under Bank profile; anything left blank turns the rules that need it into “not checked”.
    • Your earlier submissions as stored at the BSP. Add the earlier files under Earlier periods to run the period-on-period rules.
    • CHECK- findings are this tool’s own sanity checks. They are not BSP rules and are always warnings.
    • An empty sheet in the Excel template is treated as a schedule that was not submitted.
    • This page cannot send a file to the BSP by itself. Run node submit.js ui on your PC to get the same page with “Send to sandbox” and “Submit to the BSP” buttons; that program holds the bank’s certificate.
